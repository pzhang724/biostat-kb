Correction:
- TU ≈ baseline — roughly right (the target/non-target roster is set at baseline), BUT not strictly: TU also gains NEW-lesion rows at later visits. So TU = lesion IDENTITY (baseline roster + new lesions appended), not purely baseline.
- TR = post-baseline — NOT quite. TR holds measurements at EVERY visit INCLUDING baseline. The baseline SoD (50+30=80) IS a TR row at screening. So TR = all-timepoint measurements, baseline included — not post-baseline-only.
- RS = interpretation of the response — yes, essentially right. RS is the per-visit overall response VERDICT, derived by integrating the TR target measurements + non-target state + new lesions.

Refined: TU = identity (who, mostly baseline + new lesions later); TR = measurements over time INCLUDING baseline (how big / what state); RS = response verdict (so what). The baseline/post-baseline split doesn't map cleanly onto TU/TR because both carry baseline rows.
