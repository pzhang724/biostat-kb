# Last Assessment

The final **usable** pain assessment recorded for a subject — in practice the last one **before** an intercurrent event ends clean efficacy data (typically before [[Prohibited and Rescue Medication|rescue medication]], or before [[Withdrawal due to AE or Lack of Efficacy]]), or the last scheduled assessment in the AUC window (窗口) for a completer (完成者).

- It is the anchor value that **LOCF** carries forward — see [[Imputation and Carried-Forward Methods (LOCF, WOCF, wWOCF)]].
- It marks the **cutoff** (截断点) of a subject's real data within the [[Pain Intensity AUC (0-72h)]] window: scores after rescue / withdrawal are usually replaced by imputation rather than counted, so the last assessment defines where real observation stops and imputation begins.
