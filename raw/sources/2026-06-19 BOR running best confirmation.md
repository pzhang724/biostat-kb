From chat, 2026-06-19 (follow-up to Best Overall Response)

Q: Is Best Overall Response the best response among this visit and all previous ones?

A: Yes — BOR is the best (highest-ranked) timepoint response across all evaluable assessments from baseline onward, i.e. the running "best-so-far" including the current visit and all previous ones (max over the visit sequence).

Two boundaries make it more than a naive running max:
- Window stops at FIRST PD — you cannot pick up a better response after progression; the trajectory is baseline → first PD.
- A CR/PR only counts if CONFIRMED (repeat assessment >=4 weeks later), and SD only if it lasts the protocol minimum duration.

So at any given visit, BOR = best-so-far among this visit + all prior visits; the FINAL reported BOR is that cumulative best evaluated over the entire pre-PD trajectory, subject to the confirmation / SD-duration rules.
