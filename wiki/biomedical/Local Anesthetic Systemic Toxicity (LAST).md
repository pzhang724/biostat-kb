# Local Anesthetic Systemic Toxicity (LAST)

A serious adverse reaction when a **local anesthetic** (局部麻醉药 — bupivacaine, lidocaine, ropivacaine) reaches toxic concentrations in the systemic circulation — from accidental **intravascular injection** (血管内注射) or excess dose / absorption. Two-system toxicity:

- **CNS** (中枢神经系统): early — perioral numbness (口周麻木), tinnitus (耳鸣), metallic taste, agitation; progressing to **seizures** (癫痫发作), then CNS depression / coma.
- **Cardiovascular** (心血管): hypotension, arrhythmias (心律失常), conduction block, **cardiac arrest** (心脏骤停). Bupivacaine is especially cardiotoxic.

Relevant in acute pain (急性疼痛) trials using local anesthetics for post-surgical analgesia (e.g. long-acting bupivacaine wound infiltration 伤口浸润 / nerve block 神经阻滞). Management: stop injection, airway/seizure control, and IV **lipid emulsion** (脂肪乳剂, "lipid rescue" / Intralipid).

A key safety event to monitor — typically an [[Adverse Event of Special Interest (AESI)]] and, when severe, a [[Serious Adverse Event (SAE)]]. Part of the [[Acute Pain]] thread.
