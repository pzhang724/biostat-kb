Q: ORR based on PSA 是什么意思?(follow-up in PSA / prostate-cancer thread)

A:
- ORR = Objective Response Rate: proportion of patients whose tumor shrinks to a predefined degree (a binary responder/non-responder rate). Conventionally ORR is defined by RECIST on imaging (CR + PR).
- "ORR based on PSA" = the response rate defined by a PSA criterion INSTEAD OF imaging — i.e. the PSA response rate. Standard definition is PSA50: a confirmed >=50% decline in serum PSA from baseline. (PSA30 / PSA90 thresholds also reported.)
- Why used in prostate cancer: many patients (esp. mCRPC) have bone-predominant or non-measurable soft-tissue disease, so RECIST-based ORR isn't evaluable for everyone. PSA gives a quantifiable response signal in that population.
- Caveats (PCWG3): PSA response is a biomarker/surrogate, not a substitute for radiographic response or OS. PCWG3 recommends reporting it (e.g. waterfall plots of max PSA decline) but warns against using PSA response alone as the primary efficacy measure; confirmation over time and combination with radiographic/clinical endpoints is advised.
- Stats note: it's still a binary proportion endpoint (responders / evaluable), so analyzed like any ORR — point estimate + exact CI; just the response definition is PSA-based, and the analysis population is those with evaluable baseline PSA.
