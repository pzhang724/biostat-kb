From chat, 2026-06-19 (follow-up to tumour response ordering)

Q: Where does Non-PD (Non-CR/Non-PD) fit?

A: "Non-CR/Non-PD" (often shortened to Non-PD) is the SD-equivalent for NON-TARGET / NON-MEASURABLE disease.

- Non-target lesions are judged QUALITATIVELY (present / absent / unequivocally worse), not by the ≥30% / ≥20% size thresholds used for target lesions. So you can't legitimately call PR or SD on them (those need measurement).
- Instead, the in-between state is "not CR (lesion still present, or tumour markers still above normal) AND not PD (no unequivocal progression)" = Non-CR/Non-PD.
- Favorability ordering: CR > Non-CR/Non-PD (≈ SD) > PD; NE still off-axis.
- It is the timepoint overall-response set used for patients whose disease at baseline is NON-MEASURABLE only: CR / Non-CR/Non-PD / PD / NE — note there is NO PR and NO SD in that set, because both require measurable change. Non-CR/Non-PD takes the place of SD.

So Non-PD ≈ "stable, non-measurable disease": it slots where SD would be, just for disease you can only assess qualitatively.
