# ORR based on PSA (chat)

Origin: chat Q&A, 2026-06-11 — `raw/sources/2026-06-11 ORR based on PSA.md`. Follow-up in the PSA thread.

- Question: what does "ORR based on PSA" mean?
- ORR = objective response rate, conventionally defined by RECIST imaging (CR+PR).
- ORR based on PSA = response rate defined by a PSA criterion instead — the PSA response rate, standard threshold PSA50 (confirmed ≥50% decline from baseline; PSA30/PSA90 also used).
- Used in prostate cancer because bone-predominant / non-measurable disease makes RECIST ORR non-evaluable for many patients.
- Still a binary proportion endpoint → analyzed like any ORR (point estimate + exact CI); population = evaluable baseline PSA.
- PCWG3 caveat: PSA response is a surrogate, not a substitute for radiographic response or OS; report (waterfall) but don't use alone as primary.
