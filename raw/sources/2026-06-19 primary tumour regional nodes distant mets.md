Q: What are Primary Tumour / Regional Lymph Nodes / Distant Metastases?

These are the three things T, N, M describe — by how far the cancer has spread from its origin.

- PRIMARY TUMOUR (T, 原发肿瘤) = the ORIGINAL tumour at the site where the cancer first arose — for prostate cancer, the tumour in the prostate gland itself. T describes its local extent / invasion (confined vs beyond capsule vs invading neighbours). This is the starting point.

- REGIONAL LYMPH NODES (N, 区域淋巴结) = the lymph nodes that DRAIN the primary site — the first nodes the cancer reaches via lymphatics. For prostate these are the PELVIC nodes (obturator, internal/external iliac, below the aortic bifurcation). N0 = none, N1 = regional node involvement. This is locoregional spread, still "near."

- DISTANT METASTASES (M, 远处转移) = spread to FARAWAY organs/sites beyond the regional drainage, usually via the bloodstream — for prostate most commonly BONE (M1b), also distant/non-regional lymph nodes (M1a) and viscera like lung/liver (M1c). M1 = metastatic = stage IV.

Key nuance: a lymph node is N or M depending on LOCATION — pelvic (regional) nodes = N1; non-regional nodes (e.g. para-aortic above the bifurcation, supraclavicular) = DISTANT = M1a. So "lymph node spread" isn't automatically N — distant nodes count as M.

Spread pattern (prostate): prostate (T) -> pelvic nodes (N) -> bone / distant nodes / viscera (M). Escalating distance = escalating stage.
