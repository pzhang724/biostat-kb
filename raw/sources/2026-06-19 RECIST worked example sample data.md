From chat, 2026-06-19 (follow-up — sample data for the RECIST derivation)

Q: Give a sample data worked example.

One patient, 2 target + 2 non-target lesions, four visits.

TU (lesion identification):
- T1  Liver   TARGET
- T2  Lung    TARGET
- NT1 Bone    NON-TARGET
- NT2 Pleura  NON-TARGET

TR (longest diameter, mm) by visit, with SoD = T1 + T2:
- T1:  Wk0 50, Wk8 30, Wk16 28, Wk24 40
- T2:  Wk0 30, Wk8 20, Wk16 17, Wk24 25
- SoD: Wk0 80, Wk8 50, Wk16 45, Wk24 65

Derived per visit:
- Wk0  SoD 80, nadir 80 — baseline reference; non-target present.
- Wk8  SoD 50, nadir 50; vs baseline (50-80)/80 = -37.5% (>=30% down) -> Target PR; non-target Non-CR/Non-PD; no new -> Overall PR (UNCONFIRMED).
- Wk16 SoD 45, nadir 45; vs baseline -43.8% -> Target PR; Overall PR -> this CONFIRMS the Wk8 PR (>=4 weeks apart).
- Wk24 SoD 65, nadir 45 (from Wk16); vs nadir (65-45)/45 = +44.4% (>=20%) AND absolute +20 mm (>=5 mm) -> Target PD; no new -> Overall PD.

BOR = PR (confirmed at Wk16), achieved before first PD (Wk24). Responder = YES (BOR in CR/PR), so this patient counts toward ORR.

Teaching points the example shows:
- PR is judged vs BASELINE (80); PD is judged vs NADIR (45) — the two reference points differ.
- nadir updates downward each time SoD hits a new low (80 -> 50 -> 45), then stays 45.
- a single PR at Wk8 isn't enough; the Wk16 PR confirms it.
- after PD at Wk24 the window closes; even a later shrinkage wouldn't raise the BOR.
