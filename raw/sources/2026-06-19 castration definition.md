Q: What is the definition of castration?

A: Two senses:
1. The intervention — reducing/eliminating testosterone (androgen) production so it can no longer fuel the cancer. Achieved surgically (orchiectomy = remove the testes, which make ~90-95% of testosterone) or medically (ADT: LHRH/GnRH agonists e.g. leuprolide/goserelin, or antagonists e.g. degarelix, which suppress the hypothalamic-pituitary-gonadal axis so the testes stop producing testosterone).
2. The state/level — serum testosterone below a "castrate level." Conventional threshold: testosterone < 50 ng/dL (1.7 nmol/L), set historically because surgical castration achieved roughly that. Stricter/modern definition: < 20 ng/dL (0.7 nmol/L), since true post-orchiectomy levels are ~15 ng/dL; trials/guidelines (e.g. EAU) increasingly use the lower cutoff. The protocol specifies which threshold.

Why: prostate cancer is androgen-driven, so castrate testosterone slows it — the backbone of advanced prostate cancer treatment.

Link to CRPC: "castration-resistant" means the disease progresses WHILE testosterone is confirmed at castrate level (<50 ng/dL) — so castrate testosterone must be ongoing/confirmed to call it CRPC.
